# Tad-s-python-project
It's a traditional "gebeta" desktop game made with python using simple libraries like tkinter and JSON. It basically let's you play with AI which has different levels and you can also play PvP.
## How to run this project

1. Install Git
2. Clone the repository:

git clone https://github.com/Tadiwos09-coder/Tad-s-python-project.git

3. Go into the folder:

cd Tad-s-python-project

4. Run the project:

python main.py
